# Environmental & Genetic Data Processing

## Environmental Data Processing

I have completed the environmental data processing for our seascape sites, our experimental populations source sites, and the mesocosms. The majority of this data processing is in the script "EnvDatProcess.Rmd"

### Seascape Data

Seascape data, store in "summary_env_data_meadows_GEA.csv", comes directly from Steffi's GEA project. This data covers summer months, specifically between June 1 and August 31, of the years 2011-2021. The following variables are in this data: region, site_full, site, lon, lat, current temperature & salinity median, current salinity temperature maximum, current salinity minimum, and future temperature & salinity under emissions scenario RCP8.5.

### Experimental Populations Data

I had to gather new data from Per Jonsson's Symphony model and from the Copernicus Baltic Sea Reanalysis model [BALTICSEA_MULTIYEAR_PHY_003_011](https://data.marine.copernicus.eu/product/BALTICSEA_MULTIYEAR_PHY_003_011/files?subdataset=cmems_mod_bal_phy_my_P1D-m_202303) for all of my experimental populations for my experimental populations. Per's data was sent directly to me as summary statistics (this model is not publically available), so I am unable to use quantiles for any of the environmental data. I have to use medians, as this is what I was provided. The data from Per includes median temperature and salinity for all of my experimental populations, but not any minimums or maximums - this is where the other data from the Copernicus model comes in.

I downloaded the BALTICSEA_MULTIYEAR_PHY_003_011 data as netCDF files for the summer months of 2011 to 2021 in order to match the time period used by Steffi to create the seascape dataset. Using the ncdf4 package, I was then able to process this data to extract the same variables as used by Steffi in her GEAs. This data is processed in the script "ncDat_process.R"

The experimental population environmental data from Symphony had to be adjusted to more accurately reflect coastal temperatures, since the model he uses is meant for open water and does not have high coastal resoluation. Marlene had already ground-truthed data to determine the necessary correction factors. Following this convention, I adjusted median temperature by +4ºC for all sites, and median salinity on the West coast only by -5psu. 

### Mesocosm Data

To characterize the environment in our mesocosm, I processed temperature data from our HOBO loggers (recorded every 15 mins) and salinity data from our daily checks (recorded every 3 days). Temperature data is processed in the script "exp_hobo_loggers.R", as is the salinity data from our daily checks.

To process the HOBO logger temperatures, I combined the files from all different loggers then trimmed the data to only the experimental period. I also read in data from a logger deployed in a nearby eelgrass meadow, and used this to compare against my control temperatures to ensure that the control tanks were truly reflective of baseline meadow conditions - everything lined up very well. To process salinity data, I used the daily checks data to get bag level salinity data. From both datasets, I extracted mean, median, maximum, and minimum temperature/salinity. 

### Downstream Environmental Data Processing

Once I had all my raw environmental data prepped, I scaled and standardized it, then calculated environmental distance. 

To scale my data, I put it all together into a single dataframe, then used vegan's "scale" function. I then split the data back into each respective dataset (seascape, experimental source, mesocosm) before expanding these out to have one row per individual for genotype based models. Allele frequency based models have only one row per population, so for these I do not the expanded dataset. At this point, data was exported as both .csv and .env formats for downstream analysis.
